Signed in with Google

Finish Firebase connection

  1. In Firebase Console, open Project settings → General → Your apps → RIVOX Web app.
  2. Choose Config under SDK setup. Copy the values for apiKey, authDomain, projectId, appId (and messagingSenderId if shown).
  3. Open this HTML file in a text/code editor. Find PASTE_YOUR_FIREBASE_CONFIG_HERE and replace the placeholder object with your real firebaseConfig object.
  4. Host the file on an authorized HTTPS domain (or test on localhost). In Firebase Authentication → Settings, add that domain to Authorized domains if it is not already listed.
  5. Reload the hosted page and press Continue with Google.
Safety: never put a service-account private key or any server secret in this HTML file. Firebase web config is client-side config; secure your data with Firebase Security Rules.
